Exam subject settings

Edit Exam total marks for each subject (numbers only, decimals allowed). This is the paper total teachers enter marks out of (for example 50 or 75). When it is 100 (or left empty for the default 100), stored marks match a 0–100 scale. Other totals scale to a percentage the same way: % = marks ÷ total × 100. Parent and progress views use that percentage. The Report % preview column updates as you type so you can confirm scaling before saving. Leave a field empty and save to clear a custom value and use the default (100) again.

Combine exam subjects

Select subjects to show as one column on the marks sheet. Names and codes are joined with /. When you save a combination, those papers’ exam totals are rescaled proportionally so they sum to 100 (same relative weights). The combined column uses one unified percentage (0–100), saved proportionally on every paper. Removing the combination restores the previous totals from before you combined them.
